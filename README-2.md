LLM  = LARGE LANGUAGE MODEL


GPT = GENERATIVE PRE-TRAINED TRANSFORMER


GENERATIVE(GERADOR) = ELE GERA TEXTO TOKEN POR TOKEN

PRE-TRAINED(PRÉ-TREINADO) = ANTES DE VIRAR "ASSISTENTE", ELE É TREINADO COM UMA QUANTIDADE ENORME DE TEXTO PARA APRENDER PADRÕES GERAIS DA LINGUAGEM.

TRANSFORMER = É A ARQUITETURA USADA POR CONSEGUIR "PRESTAR ATENÇÃO" EM PARTES IMPORTANTES DO TEXTO (ATTENTION).


1 - TOKENIRIZAÇÃO - TEXTO É QUEBRADO EM TOKENS(PEDAÇO DE PALVRAS)

2 - EMBEDDINGS - CADA PALAVRA VIRA UM VETOR DE NUMEROS

EMBEDDINGS - CAPTURAM SIMILARIDADE E RELACIONAMENTO

COMO MODELO DE EMBEDDINGS SÃO TREINADOS ?

* PREVER UMA PALAVRA QUE ESTÁ FALTANDO;
* PREVER QUAIS PALAVRAS COSTUMAM APARECER PERTO DENTRO DO MESMO CONTEXTO;
* PALAVRAS USADAS DE FORMA PARECIDA FICAM PROXIMAS;
* RELAÇÕES RECORRENTES VIRAM "DIREÇÕES" NO ESPAÇO;
* REI E RAINHA APARECEM EM CONTEXTOS MUITO PARECIDOS (COROA, TRONO, MONARQUIA...)
* MAS DIFEREM NA DIMENSÃO/"DIREÇÃO" ASSOCIADA A MASCULINO VS FEMININO;

"REI" = "REALEZA" + "MASCULINO"
"RAINHA" = "REALEZA" + "FEMININO"
"PARIS" - "FRANÇA" + "ITALIA" = "ROMA"
"PRINCIPE" - "HOMEM" + "MULHER" = "PRINCESA"

RESUMINDO :
EMBEDDINGS REPRESENTAM PALAVRAS COMO VETORES, E A POSIÇÃO DESSES VETORES É MOLDADA PELO CONTEXTO SEMÂNTICO:PALAVRAS QUE APARECEM EM CONTEXTOS PARECIDOS, FICAM PRÓXIMAS;

3 - TRANSFORMER PROCESSA O CONTEXTO


ATTENTION PERMITE QUAIS PARTES DO CONTEXTO SÃO MAIS RELEVANTES - TRANSFORMER É O "CÉREBRO" DO LLM

ANTES DO TRANSFORMER DOIS PROBLEMAS PRÁTICOS:

1 - DIFICULDADE COM LONGAS DISTÂNCIAS
2 - TREINO POUCO PARALELIZÁVEL

O TRANSFORMER RESOLVEU ISSO AO :
* ANALISAR TOFOS OS TOKENS DE UMA VEZ (PARALELO)
* PERMITIR RELAÇÕES DIRETAS ENTRE TOKENS DISTANTES VIA ATTENTION

O QUE ENTRA NO TRANSFORMER ?
TEXTO -> TOKENS (TEXTO CONVERTIDO TOKENS)
TOKENS -> VETORES

ANTES DE USAR ATTENTION O MODELO NORMALMENTE ADICIONA INFORMAÇÃO DE POSIÇÃO, PORQUE OS EMBEDDINGS POR SI SÓ NÃO DIZEM A ORDEM.

- TRANSFORMER PRECISA SABER : "CACHORRO MORDEU O HOMEM" É DIFERENTE DE "HOMEM MORDEU O CACHORRO"

CORAÇÃO DO TRANSFORMER É CONHECIDO POR : SELF-ATTENTION
SELF-ATTENTION SEGUINIFICA QUE CADA TOKEN PODEM OLHAR PARA OS MESMOS TOKENS DA MESMA FRASE DE DECIDIR O QUE QUE IMPORTA, PESOS DIFERENTES PARA CADA UM DELES.

FRASE 1: "A MARIA CONTOU PARA A ANA QUE ELA FOI PROMOVIDA" , O TOKEN 'ELA' PODE SE REFERIR A ELE OU A ELA.

FRASE 2 : " O GATO SENTOU NO TAPETE PORQUE ESTAVA CANSADO"

OUTRO OBJETO INTERESSANTE É TER VÁRIAS ATENÇÕES EM PARALELO :

MULTI-HEAD ATTENTION:
VÁRIAS ATENÇÕES EM PARALELO

ATTENTION PODE USAR MAIS DE UMA 'CABEÇA' MAIS DE UMA AÇÃO SÃO EXECUTADAS EM PARALELO , CADA CABEÇA PODE APRENDER UM TIPO DE RELAÇÃO, EXEMPLO:

-> CONCORDÂNCIA GRAMATICAL (SINTAXE);
-> REFERÊNCIA ("ELA" APONTA PARA QUEM?);
-> RELAÇÃO ENTRE TÓPICO E DETALHE;
-> PADRÕES DE CÓDIGO (ABRIR/FECHAR CHAVES, CHAMADAS, IMPORTS).


EMBEDDINGS:
COLOCAM PALAVRAS/TOKENS NO ESPAÇO NUMÉRICO COM SEMÂNTICA

TRANSFORMER:
PEGA ESSES VETORES E CRIA VERSÕES CONTEXTUALIZADAS DELES
